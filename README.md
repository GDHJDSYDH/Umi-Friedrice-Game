# 羽未的炒饭游戏（Umi-Friedrice-Game）

> 《Summer Pockets》同人二次创作网页炒饭小游戏 🍳☀️

在线游玩地址：[https://gdhjdsydh.github.io/Umi-Friedrice-Game/](https://gdhjdsydh.github.io/Umi-Friedrice-Game/)

## 游戏特色

- **鸟白岛夏日厨房第一人称视角**：还原加藤家厨房的浅青绿墙壁、午后斜阳、电饭煲与冰箱，正对不锈钢燃气灶台开启烹饪！
- **4 种锅具 Buff / Debuff**：中华熟铁圆底锅、羽未同款红底不粘锅、厚底蓄热铸铁锅、薄壁铜制极速炒锅，各有热惯性、锅气上限、焦糊速率与 QTE 判定加成。
- **20 种精选配菜（海鲜 / 肉类 / 蔬菜，含香菇与西兰花）**：全类别合计最多选 4 种，基础隔夜冷米饭与农家鲜鸡蛋默认自带；选好的食材陈列在灶台旁，完全自由决定何时下锅！
- **丰富灶台交互与五味化学**：煤气灶点火与 5 档火力调控（支持 `0~5` 快捷键）；食用油、海盐、酱油、白糖、味精、香料、夏日百花蜜 7 种调味料，支持【金包银】【锅边呛酱油】【热油爆香】【蜜汁焦糖】等隐藏高阶触发！
- **木铲翻炒 QTE**：点击木铲/锅体或按 `Space` 触发动态 QTE（`Excellent` / `Great` / `Good` / `Bad`），实时带动锅内米粒与配菜抛起翻炒！
- **六维精密评分系统（严格均分 ≤ 100 分）**：从「火候与锅气、熟度与时序、翻炒技法、调味平衡、搭配与色泽、出锅把控」六大维度综合评价，并由 Q 版加藤羽未坐在餐桌旁展示 5 档品尝表情差分与点评！

## 本地运行

```bash
npm install
npm run dev
```
